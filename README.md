# 📊 Statistics Practice Repo

This repository is a structured collection of statistics concepts, coding exercises, simulations, and mini-projects using Python.  
It is designed to build strong foundations in statistics for data analysis, data science, and technical interviews.

---

## 🎯 Purpose

The goal of this repo is to:

- Strengthen understanding of core statistical concepts
- Practice applying statistics in Python
- Build intuition through simulations and real datasets
- Prepare for data analyst / data science interviews

---

## 🧠 Topics Covered

### 📌 Descriptive Statistics
- Mean, median, mode
- Variance and standard deviation
- Percentiles and IQR

### 📊 Probability
- Basic probability rules
- Distributions (normal, binomial, etc.)
- Law of large numbers

### 🔬 Statistical Inference
- Hypothesis testing
- T-tests
- Chi-square tests
- Confidence intervals

### 🔗 Relationships Between Variables
- Correlation
- Linear regression
- Covariance

### 🎲 Simulations
- Monte Carlo simulations
- Random sampling experiments
